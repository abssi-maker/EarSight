# Report format

Every step ends with this report. No more, no less.

```
STEP N — [name]
Built:     [1-3 lines — what now works that didn't before]
Skill:     [what you installed, or "none"]
Test:      [Playwright test name + pass/fail, or "local run — see output below"]
Changed:   [anything done differently from the plan, and why]
Uncertain: [what you guessed at]
Next:      [one line]
[screenshot or CLI output]
```

Under 150 words total (not counting the screenshot/output block).
Not a blog post. Not a list of every file touched. Not your reasoning.

After reporting: **stop and wait**. Do not start the next step until Alami replies.
